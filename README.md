# Perrito Escape Fácil (Android)

Juego de laberintos fáciles para niños hecho en Kotlin y Jetpack Compose.

## Estructura del repositorio
- `app/src/main/java/com/luiyigames/dogescape/LevelData.kt`: Definición de los niveles fáciles.
- `app/src/main/java/com/luiyigames/dogescape/MainActivity.kt`: Pantalla de selección de niveles, tablero y controles táctiles.
- `.github/workflows/build-apk.yml`: Flujo de GitHub Actions que genera el APK automáticamente al hacer push a `main`.
